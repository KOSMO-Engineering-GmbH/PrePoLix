Bundled components
------------------

Gmsh 4.15.2 (in usr/lib of the AppImage)
    Geometry import and meshing. Copyright (C) 1997-2025 Christophe
    Geuzaine and Jean-Francois Remacle. GNU GPL version 2 or later with
    an exception for Netgen, METIS and OpenCASCADE, see
    licenses/GMSH-LICENSE.txt and licenses/GMSH-CREDITS.txt.
    The library is the unmodified official Linux package from PyPI
    (https://pypi.org/project/gmsh/4.15.2/).
    Source: https://gitlab.onelab.info/gmsh/gmsh/-/tree/gmsh_4_15_2

    Gmsh contains, among others:

    Open CASCADE Technology (OCCT)
        PrePoLix uses functions of Open CASCADE Technology through Gmsh.
        GNU LGPL version 2.1 with the Open CASCADE exception, see
        licenses/OCCT-LGPL-2.1.txt and licenses/OCCT-LGPL-EXCEPTION.txt.
        Source: https://github.com/Open-Cascade-SAS/OCCT

    Netgen, TetGen/BR, HXT and more, see licenses/GMSH-CREDITS.txt.

System libraries (in usr/lib of the AppImage)
    Libraries Gmsh needs that are not part of every Linux system (GLU, Xft,
    OpenMP and others), copied unmodified from Ubuntu. Their copyright files
    are in usr/share/doc/<package>/copyright of the AppImage, the source is
    available from https://packages.ubuntu.com.

Noto Sans (embedded in prepolix)
    SIL Open Font License 1.1, see licenses/NotoSans-OFL.txt.

Rust libraries (compiled into prepolix)
    egui, eframe, wgpu, glam, cpal, rfd and more under the MIT or Apache-2.0
    license. Cargo.lock in the PrePoLix source lists them with versions; the
    license texts are with each package on https://crates.io.

CalculiX ccx 2.23 (in usr/lib/prepolix/ccx of the AppImage)
    The solver. Copyright (C) 1998-2025 Guido Dhondt. GNU GPL version 2 or
    later, see ccx/licenses/CalculiX-GPL-2.0.txt. Built by
    scripts/build_ccx.sh of PrePoLix from CalculiX 2.23 with the fixes of
    conda-forge's CalculiX package, with the SPOOLES, PaStiX and ARPACK
    solvers linked in; ccx/SOURCE.txt lists the exact sources.
    Source: https://github.com/Dhondtguido/CalculiX with the fixes at
    https://github.com/conda-forge/calculix-feedstock/tree/9d06fb5716f31488e18f67d13956164a6857e05c

    Linked into ccx:

    SPOOLES 2.2
        Public domain. With conda-forge's fixes for its multithreaded solver.
        Source: http://www.netlib.org/linalg/spooles/ and
        https://github.com/conda-forge/spooles-feedstock
    PaStiX 6.0.1 (PaStiX4CalculiX)
        CeCILL-C license, see ccx/licenses/PaStiX-CeCILL-C.txt. Copyright
        Bordeaux INP, CNRS, Inria and Université de Bordeaux; the version
        adapted for CalculiX.
        Source: https://github.com/Kabbone/PaStiX4CalculiX with the patches
        in installer/ccx/patches of the PrePoLix source.
    Scotch 7.0.11
        CeCILL-C license, see ccx/licenses/Scotch-CeCILL-C.txt.
        Source: https://gitlab.inria.fr/scotch/scotch
    ARPACK-NG 3.9.1
        BSD license, see ccx/licenses/ARPACK-LICENSE.txt.
        Source: https://github.com/opencollab/arpack-ng
    OpenBLAS 0.3.30, with LAPACK
        BSD license, see ccx/licenses/OpenBLAS-LICENSE.txt and
        ccx/licenses/LAPACK-LICENSE.txt.
        Source: https://github.com/OpenMathLib/OpenBLAS
    GCC runtime libraries (libgfortran, libgomp, libgcc, libquadmath)
        GNU GPL version 3 with the GCC Runtime Library Exception, see
        ccx/licenses/GPL-3.0.txt and
        ccx/licenses/GCC-RUNTIME-LIBRARY-EXCEPTION.txt.
        Source: https://gcc.gnu.org

    Another CalculiX can be set under Tools > Settings > CalculiX.
